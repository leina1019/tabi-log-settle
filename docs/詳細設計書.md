# TabiLog 詳細設計書 (Detailed Design)

## 1. システムアーキテクチャ
TabiLogは、ViteベースのReact SPA（Single Page Application）として構築されています。

### 1.1 全体構造 (Mermaid)
```mermaid
graph TD
    User[ユーザー] --> App[App.tsx / Main Logic]
    App --> UI[UI Components / Views]
    App --> State[React State / Context]
    App --> LS[Local Storage / Cache]
    App --> FB[Firebase Realtime DB]
    
    subgraph Services
        Weather[weatherService.ts]
        Exchange[exchangeService.ts]
        Sync[syncService.ts]
    subgraph UI Components
        Dashboard[Dashboard.tsx]
        Itinerary[ItineraryView.tsx]
        Expense[ExpenseList.tsx]
        Ticket[TicketView.tsx]
        Packing[PackingView.tsx]
        Settings[SettingsView.tsx]
    end
```

## 2. データモデル (Data Models)
`types.ts` に定義されている主要なインターフェースです。

### 2.1 旅行データ (TripData)
旅行全体の情報を保持するルートオブジェクト。
- `id`: 文字列 (Firebase Key)
- `name`: 旅行名
- `startDate`, `endDate`: 期間
- `expenses`: `Expense[]`
- `itinerary`: `ItineraryItem[]`
- `tickets`: `Ticket[]`

### 2.2 支出 (Expense)
- `paidBy`: 支払者ID
- `splitWith`: 割り勘対象者IDの配列
- `amount`, `currency`: 金額と通貨コード
- `exchangeRate`: 決済時の対JPYレート

### 2.3 旅程 (ItineraryItem)
- `type`: 'move', 'activity', 'stay' 等
- `location`: 地点名（天気予報の検索に使用）
- `link`, `mapUrl`: 外部・地図リンク

### 2.4 チケット (Ticket)
- `type`: 'flight', 'hotel' 等
- `provider`: 航空会社/ホテル名
- `referenceNumber`: 予約番号

## 3. 主要コンポーネント設計

### 3.1 App.tsx (Main Controller)
- **状態管理**: `useState` による全データの集中管理。
- **同期ロジック**: Firebaseの `onValue` を使用したリアルタイム更新と、`localStorage` へのバックアップ。
- **ルーティング**: シンプルな `view` ステートに基づいた条件付きレンダリング。

### 3.2 ItineraryView.tsx
- **日付選択**: タブ形式での日付切り替え。
- **天気表示**: `weatherService.ts` を呼び出し、選択された日の予報（アイコン・気温）をリストに統合。
- **タイムライン構成**: 垂直線を用いた時系列表示。

### 3.3 TicketView.tsx
- **プレミアムデザイン**: チケットパンチ（ノッチ）と点線セパレーターをCSSで実装。
- **リンク管理**: マップ連携を廃止し、チケットURL（Boarding）への導線を最大化。

### 3.4 PackingView.tsx
- **進捗表示**: `packedBy` 配列長と全体人数を比較し、メンバーごとのチェック状況をドーナツグラフ（SVG）や進捗バーで表示。

## 4. 外部API連携

### 4.1 Weather Service (weatherService.ts)
- `open-meteo.com` を利用。
- `geocoding`: 場所名から緯度経度を取得。
- `forecast`: 7日間（当日含む）の予報を取得し、キャッシュ。

### 4.2 Exchange Rate Service
- `openexchangerates.org` を利用。
- JPYをベースとした最新の為替レートを取得し、支出入力時の初期値として提供。

## 5. UI/UX デザインガイドライン
- **Color Palette**: `ocean-dark`, `primary` (TabiLog Blue), `accent` (Orange), `ink` (Dark Black).
- **Typography**: `Outfit` (Headings), `Inter` (Body).
- **Glassmorphism**: 半透明の背景と `backdrop-blur` を多用し、奥行き感を演出。
