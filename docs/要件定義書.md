# TabiLog 要件定義書 (Requirements Definition)

## 1. 概要
TabiLog（たびログ）は、旅行の計画から精算までを一元管理できる、体験を重視したプレミアムな旅行管理アプリケーションです。「誰が」「いつ」「どこで」「何をしたか」を美しく記録し、複雑な割り勘や持ち物管理をシンプルに解決します。

## 2. ビジネスゴール
- **ユーザー体験の向上**: 旅行中の煩わしい計算や記録を自動化・簡略化し、旅行そのものを楽しむ時間を最大化する。
- **プレミアム感の提供**: 洗練されたUI/UXにより、旅行の計画・記録作業自体をワクワクする体験に変える。
- **円滑なグループ旅行**: メンバー間の情報共有と精算を透明化し、トラブルのない旅行を実現する。

## 3. ユーザー機能要件

### 3.1 ダッシュボード (Dashboard)
- 旅行の全体予算と現在の支出合計の表示。
- メンバー別の支出割合とカウントダウン表示。
- 旅行名、期間の概要表示。

### 3.2 旅程管理 (Schedule / Itinerary)
- 日付別のタイムライン表示。
- スポットごとの位置情報、メモ、リンクの管理。
- 天気予報の自動取得と表示（Locationに基づく）。
- 複数リンク（予約サイト、地図など）への対応。
- 画像（OGP画像含む）の表示。

### 3.3 支出・精算管理 (Expenses & Settlement)
- 複数通貨（JPY, AUD, USDなど）のサポートとリアルタイム為替レート（Open Exchange Rates）の利用。
- 「誰が払い、誰と分けるか」を柔軟に指定できる割り勘機能。
- 参加メンバーに応じた自動精算アルゴリズムによる、最小送金回数の算出。

### 3.4 電子チケット管理 (Tickets)
- 搭乗券（Boarding Pass）を模したプレミアムなカードデザイン。
- 航空券、ホテル、イベント等のカテゴリ別管理。
- 予約番号、時刻、メモ、リンクの保存。

### 3.5 持ち物リスト (Packing List)
- カテゴリ別の持ち物管理。
- 「全員共通」と「個人用」の出し分け。
- メンバー別のチェック進捗状況の可視化。

### 3.6 設定・カスタマイズ (Settings)
- メンバープロフィールの編集（名前、アバター、テーマカラー）。
- 旅行基本情報（期間、カバー画像）の変更。
- Firebaseを用いたリアルタイム同期機能。
- サンプルデータのインポート/リセット機能。

## 4. 非機能要件
- **UI/UX**: モダンでプレミアムなデザイン（Glassmorphism, タイポグラフィの重視）。
- **レスポンシブ**: スマートフォン、タブレット、PCの各デバイスに最適化されたレイアウト。
- **オフライン体験**: localStorageを活用した高速な初期読み込みと変更の即時反映。
- **データ永続性**: Firebase Realtime Databaseによる複数デバイス間での同期。

## 5. 技術スタック
- **Frontend**: React (TypeScript), Vite
- **Styling**: Tailwind CSS
- **Database**: Firebase Realtime Database
- **APIs**:
  - Open Exchange Rates (為替レート)
  - Open-Meteo (天気予報)
  - Firebase (データ同期)
